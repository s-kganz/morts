## Mortality timeseries analysis

This project uses time series analysis to study forest mortality events in the western US. Given a set of mortality events detected from satellite imagery, we are interested in answering the following questions:
 - How specific are optical, thermal, and radar products as distinguishing mortality and non-mortality pixels?
 - How early can we detect a change in the annual cycle of those signals as a mortality event progresses?

## Installation
To set up this repository on your machine, clone it and then use `uv` to install the environment.
```
git clone https://github.com/s-kganz/morts.git
cd morts
uv sync
```
